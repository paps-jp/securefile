# セキュファイル便 — Windows 右クリッククライアント

ファイルを右クリックして **「セキュファイル便で送る」** を選ぶと、既定のブラウザで
アップロード画面が開き、そのファイルが選択済みの状態で表示されます。保存期間・
ダウンロード回数・パスワードを確認して「アップロード」を押すだけで、`up.paps.jp`
へ安全に送信できます。

- **ランタイム不要**：C 製の単一 `.exe`（約 300 KB、静的 CRT）。.NET も VC++ 再頒布
  パッケージも要りません。
- **サーバー変更なし**：ブラウザ版とまったく同じ公開 API を使います。
- **管理者権限不要**：右クリックメニューは `HKCU`（現在のユーザー）だけに登録します。

## なぜヘルパーが要るのか

ブラウザのセキュリティ上、外部から「ローカルのファイルパス」をファイル選択欄へ
渡すことはできません。そこでこの小さなヘルパーが、選ばれたファイルを保持したまま
ブラウザにローカルページを開き、送信を代行します。暗号化はサーバー側で行われるため
（ブラウザ版と同じ仕組み）、ヘルパー自身は暗号処理を持ちません。

## 起動方法（3通り）

- **右クリック →「セキュファイル便で送る」**：選んだファイルをそのまま送信（下記「仕組み」）。
- **アプリを起動（ダブルクリック等、引数なし）**：通知領域（タスクトレイ）に常駐し、
  アップロード画面（ドラッグ＆ドロップ／ファイル選択）を開きます。トレイのアイコンを
  クリックするとメニューが出ます：
  - ファイルを選択して送る… … ネイティブのファイル選択ダイアログ（複数可）
  - ドラッグ＆ドロップで送る（ブラウザ） … サイトのアップロード画面を開く
  - 右クリックメニューを登録／解除
  - 終了
- **コマンド**：`-install` / `-uninstall`（右クリックメニューの登録・解除）。

アプリのアイコンは `.exe` に埋め込まれています（Explorer とトレイに表示）。

## 仕組み

1. エクスプローラーは選択ファイルごとにこの `.exe` を `%1` 付きで起動します。
2. 最初に起動したプロセスが固定のループバックポート（`47159`）を確保して「オーナー」に
   なり、他プロセスは自分のパスを渡して終了します（複数選択を 1 回の送信にまとめる）。
3. オーナーは `127.0.0.1` の空きポートに小さな HTTP サーバーを立て、既定ブラウザで
   `http://127.0.0.1:<port>/?t=<token>` を開きます。トークンを知るページ以外は
   `/api` を呼べません。
4. ページで「アップロード」を押すと、ヘルパーが `up.paps.jp` の API へ
   セッション開始 → 分割アップロード（8 MiB／再開対応）→ 完了、を実行し、進捗を
   ページへ逐次返します。完了後、共有リンク・QR・貼り付け用メッセージを表示します。
5. ヘルパーは操作が 5 分間なければ自動終了します。

## ビルド

Visual Studio Build Tools（「C++ によるデスクトップ開発」ワークロード）が必要です。

```bat
clients\windows\build.bat
```

`securefile_send.exe` が同フォルダーに生成されます。

## インストール（右クリックメニューの登録）

```bat
securefile_send.exe -install
```

- 実行ファイルを `%LOCALAPPDATA%\SecureFileSend\` にコピーし、そこを指す
  右クリックメニューを登録します（ビルド用フォルダーを消しても動きます）。
- 送信先を変えたいとき：`securefile_send.exe -install -backend https://例`

削除：

```bat
securefile_send.exe -uninstall
```

（`%LOCALAPPDATA%\SecureFileSend` の実行ファイルは手動で削除できます。）

## 環境変数（任意）

| 変数 | 用途 |
| --- | --- |
| `SFS_BACKEND` | 送信先 URL をレジストリより優先して上書き（再インストール不要）。 |
| `SFS_URL_FILE` | 設定するとブラウザを開かず、ローカルページ URL をこのファイルへ書き出す（デバッグ用）。 |

## 構成

| ファイル | 役割 |
| --- | --- |
| `main.c` | エントリ、`-install/-uninstall`、複数選択のまとめ、起動フロー |
| `httpserver.c` | ローカル HTTP サーバー（ページ配信・`/api/files`・`/api/send` ストリーミング） |
| `uploader.c` | WinHTTP で `up.paps.jp` へ分割アップロード |
| `registry.c` | 右クリックメニューの登録・削除 |
| `util.c` | バッファ・UTF-8 変換・簡易 JSON 読み取り・埋め込み資産 |
| `assets.rc` / `ui/` | ブラウザ表示用のページ（`.exe` に埋め込み） |
